The five rules everything here follows

Neutral by default

Zinc, white, 1px borders, charcoal primary. Colour appears only where it means correct, wrong, or running out of time.

Two densities

40px rows and 13px text for the teacher; 720px measure, relaxed leading and 44px targets for the student.

Say the rule before it bites

Timers, play limits, focus monitoring and review policy are all stated in plain Vietnamese before the student can be affected by them.

Report, do not accuse

Integrity signals are evidence for a conversation. Neutral words, no alarm iconography, no automatic penalty.

Vietnamese first

Every string is written in Vietnamese first and laid out for its length. No fixed-width labels, no truncation of a verb.

Where the deck proposes something the spec does not have

Six additions, each small, each with the reason it earns its place. Everything else on these sheets implements §8 and §9 as written.

ProposalWhereWhy
Command palette (⌘K) A-02 The only navigation model that survives an LMS-sized sidebar. Cheap now, and it lets nav items be judged on use rather than findability.
“Chờ chấm” as a nav item A-00 Grading is the teacher’s recurring queue and §8 reaches it only via a monitor screen. One route, and the count is visible everywhere.
Grade by question G-04 Same endpoints, one extra query. Decides a rubric once instead of nineteen times — the largest time win available in the product.
Live “học viên sẽ đọc” preview G-01 Integrity policy is set three screens away from the words it produces. Rendering them next to the switches is what makes §10.2 actually true.
Manual-grading cost estimate G-01 “19 × 2 = 38 câu bạn sẽ phải chấm”, shown at the moment of commitment rather than discovered on Sunday night.
Saveable comment snippets G-03 The same four sentences get typed all term. A tiny table and a chip row.
