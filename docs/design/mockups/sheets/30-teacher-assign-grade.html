Teacher · assign, monitor, grade

Authoring happens once a week; this half happens every day. The screens are ordered the way the work actually flows — give the test out, watch it happen, mark what the machine cannot, and look at the integrity record only when something makes you want to.

1 · Creating an assignment

Eleven settings across five groups (§7’s Assignment). A wizard would be wrong: this is a task a teacher repeats weekly and wants to skim, not be walked through. One scrolling form, defaults already correct, and a sticky rail that shows the consequences — including the exact sentences the student will read.

G-01 Create assignment /admin/assignments/new

Two bars, not one. Earlier drafts of this board REPLACED the global top bar with the contextual one, which took the command palette and the account menu off every detail screen — on this screen there was no way to reach settings or sign out. Chrome that disappears on half the screens is chrome nobody relies on, so the global bar stays and the contextual bar sits under it. G-02 and G-06 follow the same rule; G-03 to G-05 are focus modes and drop the shell entirely.

“Học viên sẽ đọc” is the feature. Integrity policy is the setting teachers get wrong most often, because the words that reach the student are three screens away from the switch. Rendering them live next to the switches closes that gap and doubles as a review of the copy itself.
“38 câu bạn sẽ phải chấm” is a cost estimate. Two short-answer questions feel free while authoring and expensive on Sunday night. Showing the multiplication at the moment of commitment is the single most useful number on this screen.
Defaults come from §10.3 — no fullscreen, block paste, flag rather than auto-submit — and the card says so in one line, so a teacher who changes nothing knows they chose the conservative option rather than missing a step.

2 · Monitoring a live assignment

G-02 Monitor /admin/assignments/:id · polls 15s while open

One row per student, sorted so the rows that need a decision float up: in progress with time nearly gone, then not started with the window closing, then everything settled. The three interventions §8 requires — extend, reset, void — sit behind one menu and each one asks for a reason, because each one is a thing the teacher will be asked about later.

“Rời trang” is a count with no adjective. Three is amber, not red, and the column header does not say “vi phạm”. §10.4: the app reports, the teacher judges.
Every intervention takes a reason. Not for compliance — for the teacher’s own memory three weeks later when a parent asks why one student had fifty-five minutes.

G-09 Assignment · draft, scheduled, closed /admin/assignments/:id · the same route as G-02, before and after it is live

One route, four states. Draft, scheduled, open and closed are the same assignment at different moments and the teacher reaches every one of them from the same list row, so splitting them across URLs would only teach people which link to bookmark. What changes is the contextual bar — the badge and the two or three actions that are legal right now — and the block under it: draft and scheduled show the read-only summary of what G-01 saved, open shows the live table (G-02), and closed puts a results strip above the summary because the numbers are now the point. Nothing here is red: closing is reversible through “Gia hạn cho tất cả”, and a draft is not a warning, it is a thing that has not happened yet.

Đóng rồi vẫn mở lại được bằng “Gia hạn cho tất cả”.

The bar is the state machine. Each badge comes with exactly the actions that are legal now: a draft can be edited or given out, a scheduled one edited or (not yet) closed, a closed one reopened or read. Disabled buttons stay visible with the reason beside them, so the teacher learns the rule instead of hunting for the button on the next screen.
Closed is not destructive. “Gia hạn cho tất cả” reopens the window for anyone with an attempt left, so the closed state gets the secondary badge from the foundations sheet and an outline button — never red, never a warning icon (§12).
“Đóng sớm” keeps a promise. S-04 told the student the clock runs 45 minutes from the moment they press start. The confirm restates that in the teacher’s numbers and asks for one tick, so nobody refreshes the table expecting “Đang làm” to drop to zero.
G-02b Monitor · reset & void dialogs · loading, empty, error /admin/assignments/:id

Extend, reset and void are one dialog shape learned once: what will happen, one required reason, two buttons. The reason is not a formality — each intervention changes a student's record that a parent or a colleague may ask about weeks later, so the confirming button stays disabled until the reason is typed, and the note is stored with the teacher's name. Neither reset nor void deletes anything; the old attempt stays readable to the teacher, which is what makes both safe to click. The three frames below the dialogs are the table before its first fetch answers, with nobody assigned, and when the fetch fails — drawn because a monitor that shows nothing during a live test is exactly the moment the teacher cannot afford to guess.

G-04 Grade by question — the mode that saves the evening proposal · same route, a toggle

Grading nineteen attempts one at a time means re-reading the same prompt and re-deciding the same rubric nineteen times. Grading one question across nineteen students means deciding the rubric once. It is the same data, the same endpoints, and one of the largest wins available in this product for the size of the change.

Names hidden by default. Anonymous marking is a fairness feature that costs one toggle, and a single-teacher practice is exactly where unconscious expectation about a specific student is strongest.

G-08 Classes list · create · archive /admin/classes

There is no delete on this screen. A class is the root that memberships hang off, and memberships are what attempts, grades and integrity records reference; deleting one would either cascade through a term of work that must stay reviewable or fail on a foreign key, and neither is a thing a teacher should be able to trigger from a menu. Archive removes the class from every picker and leaves the record intact. Each row carries the open-assignment count and the join-code state because those are the two facts that change what archiving means — open assignments stay visible to students until they close — and the two questions a teacher actually brings to this list.
