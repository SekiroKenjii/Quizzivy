How True / False / Not Given questions work

Unit 2 · lesson 1 of 4

Each statement is about what the writer says, not about what is true in the real world. Your job is to find the part of the passage that talks about the same idea, then compare the two carefully.

{{ lr.k }}{{ lr.v }}

The hardest choice is usually between False and Not Given. Ask yourself: does the passage say the opposite? If yes, it is False. If the passage simply does not mention it, it is Not Given.

Try itPassage: "Most shop owners now support the scheme." Statement: "All shop owners support the scheme." The answer is False, because "most" contradicts "all".
