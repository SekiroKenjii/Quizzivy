One page frame for every teacher page

Today the v2 deck draws four page widths: 1320, 1080, 860 and 720px, each one centred. A teacher who moves from Assignments to New assignment sees the title jump sideways, and nothing is drawn above 1440px. This proposal replaces the four widths with one frame up to 1600px, one left edge, and one rule for text: fields and prose are capped, while cards, lists and tables fill the frame. Import upload and processing merge into one two-pane workspace. It blocks v0.10.1.

Why the form pages no longer leave a gap

A narrow column with empty space beside it is accepted practice for a single focused task, such as signing in, checking out or uploading one file. On a working page like New assignment or Settings, a 244px empty band at 1440 (sidebar collapsed), or 512px at 1920 with the sidebar open, looks unfinished. It also wastes room the stepper, the test list and the summary could use. The width limit exists to keep text readable, not to make containers narrow. So the proposal caps text and lets containers fill the frame.
