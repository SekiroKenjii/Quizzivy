A cloze is one question per gap, shown as one screen

Confirmed. A five-gap cloze counts as five questions everywhere: the strip, the progress count, the Submit dialog, the score and the result. The take-test screen gathers the gaps into one stop. Below are the four drawings engineering asked for, the copy in English and Vietnamese, and what each adds to T-D4.10. No data or API change.

Decision: one question per gap Unblocks T-D4.10 Source: work/deck-d4 @ 837b95aa

Why this answer

  1. 1The student reads one passage; the teacher marks five answers.One screen keeps the reading whole. One question per gap keeps the score, the feedback and the teacher's item analysis per gap, which is where the learning signal is.
  2. 2The count stays true.Five gaps are five points and five marks. One square for them would disagree with the score, with the Submit dialog ("5 unanswered") and with the teacher's results.
  3. 3Everything else already agrees.The builder, Word import, the bank, grading and the result all treat a gap as a question. The Student page is the only drawing that doesn't, and only in how it numbers and counts.
  4. 4Authors keep what they have.A gap can have its own prompt, points, image or audio. The screen handles each case without a new question type.
Not chosen One question with several gaps

A new question type with its own answer format, marking, result display, authoring and Word-import mapping, across taking a test, grading and results. Tests already published with gap questions would stay in the old format beside it. What students would get for that is one square instead of five, which isn't worth the risk.

Accepted differences from the Student page
  • Gap numbers are question numbers: 23–27, not 23.1–23.5.
  • The line reads a range: "Questions 23–27 of 34", not "Question 23 of 31".
  • Five linked squares where the deck draws one.
  • When gaps differ, each one's own prompt and points show in the card.

Behaviour on the card
  • Choosing writes that gap's own answer, then opens the next empty gap in the run, wrapping round. When none is empty it stays put. A polite live region says "Gap 26".
  • A to D choose for the open gap. F flags its question. The arrows and Previous / Next move by stop, so the run is one step.
  • A square, a chip, a passage gap or a "Go to 25" chip in the Submit dialog all open the run at that gap.
  • Phone: the passage is in the drawer. Tapping a gap there closes it and opens that gap; options wrap at 132px minimum.
  • Reload reopens the run at the stored open gap. The integrity record's question is the open gap's question.
  • Teacher preview: the same screen with nothing chosen and nothing saved.

  • A run is two or more gaps in a row from one group, each bound to a single-choice question, none with an image or audio of its own. Anything else is a stop of one question.
  • A gap on its own is QuestionSheet as today (image, prompt, choice rows, points), but its type says "Cloze", not "Single choice". The passage shows its chip as the open one.
